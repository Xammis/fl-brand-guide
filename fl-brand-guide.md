# Fuel Logic Brand Guide v1.0

Everything you and your AI agent needs to follow the official Fuel Logic brand standards. 

## FL-Brand-Guide Repo Location:
Hand this link to your agent when creating any type of design, document or report and you'll be following FL brand standards: 
https://xammis.github.io/fl-brand-guide/

## Fonts:
Work Sans (Google Font)
- Paragraph/Text font: Work Sans, 400 
- Headline Font: Work Sans, 700
- Button Font: Work Sans, 500
- Icons: Font Awesome Icons (Free) https://fontawesome.com/
## Font Sizes:
- H1: clamp(3.1rem,3.1rem + ((1vw - .2rem) * 1.5),4rem),4rem) 
- H2: clamp(1.85rem,1.85rem + ((1vw - .2rem) * 1.583),2.8rem)
- H3: 1.5rem
- H4: 1.3rem
- H5: 1.3rem
- H6: 1.3rem
- Paragraph/Text Size: 1.3rem
- Small text size: 0.9rem
- Button Text Size: 1.3rem
